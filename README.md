# Топливный космоконтур 2035 // Рабочее место оператора ОТУ

Интеллектуальная система планирования снабжения, материального баланса, оценки инвестиций и стресс-тестирования цислунарного орбитального топливного узла (ОТУ) на **2035–2040 годы** (с масштабированием до **2045 года**).

Разработано для серии соревнований **«КосмоХакатон 2026»** в рамках федерального проекта **«Кадры для космоса»** (АНО «КЭП», Роскосмос, МИРЭА).

---

## 🚀 Быстрый запуск

### 1. Запуск Backend API (FastAPI)
```bash
# Установка зависимостей (Python 3.12+)
pip install -r requirements.txt  # или: pip install fastapi uvicorn pydantic pandas openpyxl pytest httpx

# Запуск сервера API
py -m uvicorn src.main:app --host 127.0.0.1 --port 8000 --reload
```
* **Swagger UI (Интерактивная документация):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
* **ReDoc:** [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)
* **Встроенный веб-дашборд:** [http://127.0.0.1:8000/app](http://127.0.0.1:8000/app)

### 2. Запуск Frontend (React + Vite + Tailwind CSS)
```bash
cd frontend
npm install
npm run dev
```
* **Дашборд оператора:** [http://localhost:3000](http://localhost:3000)

### 3. Автоматизированные тесты (22 теста)
```bash
py -m pytest tests/ -v
```

## ⚙️ Физико-экономические формулы расчетного ядра

### 1. Материальный баланс
$$End\_Stock = Start\_Stock + Gross\_Delivery - Losses - Served\_Demand$$
* Потери начисляются **строго один раз на валовый приход (throughput)**:
  $$Losses = Gross\_Delivery \times \text{loss\_rate} \quad (4.5\% \text{ базовые}, \; 1.2\% \text{ при ZBO})$$
* **Отрицательный физический остаток исключен**:
  $$Served\_Demand = \min(Start\_Stock + Gross\_Delivery - Losses, \, Demand\_Total)$$
  $$Deficit = Demand\_Total - Served\_Demand \ge 0, \quad End\_Stock \ge 0$$
* Критический спрос удовлетворяется с приоритетом ($Served\_Crit = \min(Served\_Demand, Demand\_Crit)$).
* **Норматив 45-дневного страхового резерва**:
  $$R_{45d} = Demand\_Total \times \frac{45}{365}$$
  Проверяется наличие физического запаса на начало года либо покрытие законтрактованной мощностью Emergency.

### 2. Финансовые расчеты и исключение двойного счета
* **Переменный платеж канала с защитой от двойного Take-or-pay**:
  $$Var\_Payment = Unit\_Price \times \max(Order\_Volume, \, TakeOrPay\_Ratio \times Reserved\_Capacity)$$
* **Плата за резервирование**:
  $$Res\_Payment = Res\_Tariff \times Reserved\_Capacity$$
* **Стоимость хранения (0.72 млн у.е./т·год)**:
  $$Storage\_Cost = 0.72 \times \frac{Start\_Stock + End\_Stock}{2}$$
* **OPEX(t)**: сумма закупки, бронирования, хранения, фиксированного OPEX ZBO (12 млн/год) и ISRU (70 млн/год). Закупка стартового запаса 2035 года (~12.33 т) включена в затраты 1-го года.
* **CAPEX(t)**: ZBO (180 млн), Earth-New (90 млн опцион + 270 млн исполнение = 360 млн всего), Lunar-ISRU (1250 млн строго до 2038 г.).
* **Приведенная стоимость жизненного цикла (LCC / NPV при ставке $r=0.08$)**:
  $$NPV\_Cost = \sum_{t=2035}^{T} \frac{CAPEX_t + OPEX_t}{(1 + r)^{t - 2035}}$$
